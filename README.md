# 🌿 Greenden - Plant Store Website

Greenden is a modern, responsive plant e-commerce website built using **HTML5**, **Tailwind CSS**, and **JavaScript**. The project showcases a clean and user-friendly interface for browsing and exploring a variety of indoor and outdoor plants.

---

## 📖 Overview

Greenden is a front-end web development project designed to practice responsive layouts, Tailwind CSS utilities, and modern UI design principles by building a beautiful online plant store.
